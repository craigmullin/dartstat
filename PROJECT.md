# DartStat

- Responsibility: personal darts practice tracking and statistics
- Repository: `git@github.com:craigmullin/dartstat.git`
- Firebase project: `dartstat-cmullin`
- Client: React 19, TypeScript, Vite
- Platform: Firebase Google Authentication, Firestore, Hosting
- Access: multi-user; each account owns an isolated data namespace
- Design relationship: sibling of SpikeStat and consumer of Design guidance

## Product outcome

An authenticated user can complete a fast, mobile-first Cricket Practice
session, retain every dart result, and review session and lifetime statistics.
