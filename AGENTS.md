# DartStat operating instructions

DartStat is a mobile-first darts practice and statistics application. Read
`PROJECT.md`, `NOW.md`, the two DartStat handoffs, and the Design repository
guidance before substantive work. Preserve Firebase project `dartstat-cmullin`.
Store raw dart results as the source of truth and scope all user data to the
authenticated Firebase UID. Run lint, tests, and the production build. Do not
deploy or change production security rules without explicit authorization.
